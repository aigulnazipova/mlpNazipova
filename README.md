# Классификация данных с помощью многослойного персептрона
## Структура проекта
* data.csv — исходный набор данных.
* analysis.py — анализ данных, расчёт статистических характеристик и построение гистограмм.
* split.py — разделение исходного набора данных на обучающую и валидационную выборки.
* train.py — обучение многослойного персептрона, вывод метрик и построение графиков обучения.
* predict.py — загрузка обученной модели, классификация объектов и оценка качества предсказаний.
* requirements.txt — необходимые библиотеки Python.

## Установка зависимостей
python -m pip install -r requirements.txt

## Запуск проекта с нуля
1. Анализ данных: **analysis.py**<br>
Программа выводит общую информацию о наборе данных и статистические характеристики признаков, а также строит гистограммы.
3. Разделение данных: **split.py**<br>
Программа формирует обучающую и валидационную выборки из исходного файла data.csv. Для воспроизводимости используется фиксированное случайное зерно.
4. Обучение модели: **train.py**<br>
В процессе обучения выводятся значения функции потерь и точности на обучающей и валидационной выборках. После завершения обучения сохраняется файл saved_model.npy и строятся графики изменения метрик.
5. Предсказание: **predict.py**<br>
Программа загружает сохранённую модель, выполняет классификацию валидационной выборки и выводит количество правильных и ошибочных предсказаний, Cross-Entropy Loss и Accuracy.

## Настройка обучения
Параметры обучения можно задавать через аргументы командной строки. Например:<br>
python train.py --epochs 84 --batch_size 8 --learning_rate 0.0314<br>

## Используемые библиотеки
* NumPy — матричные вычисления и реализация нейронной сети.
* Pandas — загрузка и обработка данных.
* Matplotlib — визуализация данных и результатов обучения.
